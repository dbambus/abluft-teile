# Abluft-Teile (SolidCraft, FDM)

Parametrische Teile für ein Ø75-Abluftsystem mit M75×2-Gewinde.

| Ordner | Inhalt |
|---|---|
| `adapter-90grad/` | Tisch-Flansch (Ø104, 4×M4 auf 88,9) auf Ø75, 90°-Bogen R60 / R85 / R110 (Wartungsöffnung unterdrückt, in SolidCraft wieder einschaltbar) |
| `rohr/` | Rohr 250 mm mit M75×2 an beiden Enden (`rohr_l` parametrisch) |
| `wartungsdeckel/` | Deckel 88×54×4 mit O-Ring-Nut (50×2,5), 2×Ø4,5 |
| `y-stueck/` | Y-Abzweig Wand → waagerechte Leitung, 45°-Einmündung, Konus Ø75→Ø100 beginnt an der Einmündung; Muffe M75×2 links (eigener Körper); R60 / R85 / R110, Generator `gen_y_stueck.py` |

Einschmelzmuttern: ruthex RX-M4S×4,0 (Bohrung Ø5,6 × 5 mm).

Jedes Teil liegt als `.sc` (SolidCraft, parametrisch) und als `.stl` (druckfertig, mm) im jeweiligen Ordner.
